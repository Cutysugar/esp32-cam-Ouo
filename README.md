# ESP32-CAM 画面源（AI 恋人摄像头）

给 AI 恋人做的 ESP32-CAM 画面源。板子提供 `GET /capture` 返回一张 JPEG，
供同一 WiFi 下的手机 agent / 后端拉取识别；另提供 `GET /status` 返回设备诊断信息。

## 接口与特性

| 接口 | 说明 |
|------|------|
| `GET /capture` | 抓一张**新鲜** JPEG（先丢两帧旧缓存 + 等 150ms 再抓，避免出现旧画面） |
| `GET /status` | 纯文本诊断：复位原因 / 运行时长 / RSSI / 信道 / BSSID / WiFi 省电模式 / 保活计数 / OTA 主机名 |

固件层面还做了：

- **禁用 WiFi 省电**（`WiFi.setSleep(false)`）
- **双向保活心跳**：每 3 秒向上行（网关）与下行（最近访问的客户端）各发一个 UDP 小包，
  解决 **Mesh 子路由（无线回程）空闲后首次访问 TCP 握手卡十几秒** 的问题
- **OTA 无线升级**：烧录本版后，以后可通过 WiFi 更新固件，无需再插 USB
- **断线自动重连**

## 硬件

- ESP32-CAM（AI-Thinker，带 4MB PSRAM）+ 下载底板
- 摄像头 OV3660（3MP，兼容 OV2640 排线）
- Micro-USB 数据线烧录

## 烧录

### 环境

- Arduino IDE 2.x + esp32 平台（Espressif 官方）
- **开发板**：`AI Thinker ESP32-CAM`
- **分区方案**：`Minimal SPIFFS (1.9MB APP with OTA/...SPIFFS)`
  ← **必须选带 OTA 的**，否则 OTA 功能不可用
- **端口**：CH340 对应的 COM 口

### 配置

把 `esp32_cam.ino` 开头的 WiFi 名/密码改成真实的（**只能 2.4GHz**）。
OTA 密码在文件开头 `OTA_PASSWORD`（默认 `otapass1234`，建议修改）。

> ⚠️ 本仓库文件已脱敏（占位符 `你的WiFi名` / `你的WiFi密码`）。
> **本地烧录前必须改回真实信息，改完不要再推回公开仓库。**

### 上传

点上传 → 按 RST 复位 → 串口监视器（115200）看 IP。

## 使用

浏览器 / agent 直接访问：

- `http://<IP>/capture` → 看到照片即成功
- `http://<IP>/status` → 查看设备状态

同一 WiFi 下的手机 agent 可直接拉 `/capture` 的图做视觉识别。

## OTA 无线升级（烧录过一次之后）

1. 设备已连上 WiFi
2. Arduino IDE → **工具 → 端口** → 选择出现的**网络端口**（形如 `esp32cam-xxxx at 192.168.31.x`）
3. 直接点上传即可（会提示输入 OTA 密码）

> 主机名按芯片 MAC 自动生成（`esp32cam-<MAC低16位>`），多台设备不会冲突。

## 排障记录：Mesh 子路由下「空闲后首次访问卡十几秒」

### 现象

同一局域网、两台同型号同固件的 ESP32-CAM：

- 连 **主路由** 的板子：随时访问都是 ~0.3s
- 连 **Mesh 子路由** 的板子：空闲十几秒后首次访问，`connect` 要等 **17 秒**；连续访问又很快

### 定位过程

1. 用 `curl -w` 拆解耗时：时间**全花在 TCP 握手（connect）**，
   首字节 / 抓图都很快 → 问题在网络层唤醒，不在摄像头
2. `/status` 显示 `wifi_ps=NONE`（ESP32 省电已关闭）**依然复现** → 不是 ESP32 休眠
3. 路由器后台确认：该板子连的是 **Mesh 子路由**，而子路由走**无线回程**——
   空闲时回程链路进入省电，跨节点流量需要等链路唤醒

### 解决：双向保活心跳

固件每 3 秒：

1. 向**网关**发 UDP → 保持上行（子路由 → 主路由）回程路径活跃
2. 向**最近访问过它的客户端 IP** 发 UDP → 刷新客户端 ARP 缓存，
   避免因 ARP 条目过期而重新解析带来的延迟

**效果：首次 `connect` 从 17.4s → 0.02s，与主路由下的板子持平。**

相关开关（文件开头）：

- `KEEPALIVE_ENABLE`（1 开 / 0 关，可做对照实验）
- `KEEPALIVE_INTERVAL_MS`（默认 3000）
- `GW_IP`（网关地址，按自己网段改）
